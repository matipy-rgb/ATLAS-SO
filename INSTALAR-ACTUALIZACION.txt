ATLAS SO v0.9.0 — RRHH OPERACIÓN REAL Y GESTIÓN MASIVA

1. Descargá una copia completa desde ATLAS SO.
2. Conservá el respaldo de la versión anterior.
3. Ejecutá APLICAR-ATLAS-SO-v0.9.ps1 desde el paquete extraído.
4. No borres los datos del navegador ni la configuración de Supabase.
5. Ejecutá:

   npm.cmd ci
   npm.cmd run check
   npm.cmd audit --omit=dev

6. En una base existente, ejecutá al final una sola vez:

   supabase/v0.8-security-privacy-sync.sql
   supabase/v0.9-rrhh-operation.sql

   Si la base nunca recibió las migraciones anteriores, seguí el orden indicado
   en CONFIGURAR-ACTUALIZACION.md.

7. Publicá la versión solo después de que todas las pruebas pasen.
8. Recargá el sitio con Ctrl + F5 y verificá acceso, datos, marcaciones y copia
   de seguridad.

El aviso “LF will be replaced by CRLF” de Git en Windows es informativo: no
indica que el proceso se haya colgado ni que los archivos estén dañados.
